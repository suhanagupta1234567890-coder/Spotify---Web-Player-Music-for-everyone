# Spotify---Web-Player-Music-for-everyone
🎧 Spotify Frontend Clone  A clean and responsive Spotify Web Player Frontend Clone built using HTML, CSS, and Font Awesome icons. This project focuses on recreating the UI of Spotify including the sidebar, cards, and bottom music player.

🚀 Features

🎵 Spotify-like UI design
📱 Fully Responsive (Mobile + Tablet + Desktop)
🎨 Clean and modern dark theme
🎧 Bottom music player with controls
📂 Sidebar navigation
💡 Hover effects & smooth styling
🔊 Volume slider and control icons

🛠️ Tech Stack
HTML5
CSS3
Font Awesome Icon
